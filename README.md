# Smart Attendance System (AI & Computer Vision)

## 🚀 Overview
A real-time face recognition-based attendance system using deep learning and computer vision.

## 🔧 Features
- Face detection using YOLOv8
- Face recognition using FaceNet
- Multi-person tracking using DeepSORT
- SQL Server database integration
- Email notifications for attendance

## 🛠️ Tech Stack
Python, OpenCV, PyTorch, YOLOv8, DeepSORT, FaceNet, SQL Server

## ▶️ How to Run
1. Install dependencies:
   pip install -r requirement_s.txt

3. Run registration:
   python register1.py

4. Run attendance system:
   python sm_att.py

## 📂 Database
Run the SQL script in `database/att_db.sql`
